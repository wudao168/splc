# 界面设计基准

使用内置 imagegen 生成完整工作台参考 `design-concept.png`。实现使用真实数据，初始空库。

- 布局：左侧白色导航，右侧工作区；顶部标题和导入操作；四列指标；待办列表与五步流程；最近订单。
- 色彩：画布 #f5f7fa、表面 #ffffff、正文 #172b4d、辅助文字 #6b7c93、边框 #e5eaf0、主色 #117d75。
- 字体：Segoe UI、Microsoft YaHei、系统无衬线；统一为 12/14/16/24/28px 五级，分别用于辅助文字、正文与表格、区块标题、页面标题、统计数字；仅用常规和半粗两档字重。
- 组件：8px 圆角面板，细边框，轻量表格，实色主按钮，侧栏选中浅青底；图标用一致的 1.8px 描边。
- 业务延展：表单用有标题的对话框，密集明细表支持横向滚动；窄屏侧栏转换为顶部导航。
- 有意修正参考图：日期使用当前上海日期；去掉没有功能的头像和铃铛；送货单文案为发货后可开单，不要求签收；不使用渐变。
- 所有数字来自数据库，未接通的外部服务明确显示未接入。
